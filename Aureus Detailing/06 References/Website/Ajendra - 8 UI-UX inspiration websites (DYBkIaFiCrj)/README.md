# 8 websites for UI/UX design inspiration

- **Source:** https://www.instagram.com/p/DYBkIaFiCrj/ by @ajendra.uiux (a 10-slide photo carousel).
- **Saved:** 15 Nov 2026. The caption and post details are saved; the slide images aren't, because Instagram requires a login to download them. To keep the slides, open the post in the Instagram app and save the images into this folder.

## The websites (from the caption)

| Site | Use it for |
|---|---|
| [supahero.io](https://supahero.io) | Hero sections (the first screen of a homepage) |
| [selected.site](https://selected.site) | Hand-picked full website designs |
| [bentogrids.com](https://bentogrids.com) | "Bento" grid layouts, e.g. for packages and services |
| [footer.design](https://footer.design) | Website footers (contact, address, opening hours) |
| [cta.gallery](https://cta.gallery) | Call-to-action sections ("Book now" blocks) |
| [saaspo.com](https://saaspo.com) | Modern landing pages |
| [dark.design](https://dark.design) | Dark-themed websites, the closest to the Aureus navy look |
| [navbar.gallery](https://navbar.gallery) | Navigation bars and menus |

## For the Aureus website
- Start with **dark.design** and **supahero.io** for the navy, 3D hero (alongside the Octaboot reference in the parent folder).
- Use **bentogrids.com** for the Silver, Gold and Aureus package cards.
- Use **cta.gallery** for the hot-pink "Book now" sections.
