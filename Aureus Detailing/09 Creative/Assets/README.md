# Assets (everything behind the final reels)

Finished videos live in `../Reels/`. This folder holds what was used to make them.

| Folder | What's in it |
|---|---|
| `Reference Reels/` | The 4 Instagram reels we studied (other businesses' work: reference only, never repost) |
| `Trainer Character/` | The master detailer's character board |
| `Brand Launch Project/Notes/` | Brief, shot lists, Higgsfield prompts, shoot page |
| `Brand Launch Project/Scripts/` | Free local editor and generators (run with `~/local-ai/.venv/bin/python`) |
| `Brand Launch Project/Audio/` | AI voices (`voice` = light Aussie, `voice-v2` = old Aussie "Voice 3"), music, detailing sounds |
| `Brand Launch Project/Shots/` | Higgsfield video shots: Set 1 (pearl-white sedan, Reels A and C), Set 2 (G-Wagon, Reel B) |
| `Brand Launch Project/Keyframes/` | The still images each shot started from |
| `Brand Launch Project/Archive/` | Superseded: Reel B v1 (pearl-white sedan), stand-in animatics |

Rebuilding a reel writes to `Brand Launch Project/Renders/`; copy the final into `../Reels/<category>/`. Earlier ad project files (v1 to v6) stay in `08 Social Media/Launch Reels/`.
