# Aureus website storyboard: 13 consistent image prompts (for Higgsfield)

Written 16 Nov 2026. Generate these one by one to design the full website and its motion. Every prompt starts with the same **look block**, so all images share one car, one wash bay, one interface style and one palette.

## How to keep every image consistent
1. **Make #4 first.** It's the master frame: the finished hero.
2. Pick the best result and **attach it as a reference image** to every later prompt (in Higgsfield: Image reference / omni-reference). Also attach the logo: `Aureus Detailing/02 Logo/Icons/social-profile-1080.png`.
3. Use the **same model and settings** for all: GPT Image 2.6 (best with interface text), highest quality. Desktop frames 16:9; mobile frames 9:16.
4. If a seed is shown, reuse the master's seed.
5. Never change the look block. Only the scene part changes.
6. Save each keeper to `Aureus Detailing/07 Website/storyboard/` as `01-lights-on.png`, `02-foam-reveal.png` and so on.

## The look block (used at the start of every prompt)
> Photorealistic website screen design for "Aureus Detailing", a premium car detailing brand in Perth. Setting: a dark luxury wash bay at night, deep navy (#071A33) walls, thin aqua (#00A8A8) LED light bars overhead, a mirror-wet black floor with reflections. Car: one sleek deep-navy metallic luxury electric SUV, no badges, no number plate text. Interface: frosted wet-glass panels with real water droplets, a 3D polished chrome letter "A" logo with a small hot-pink cap beside the word "AUREUS" in a frosted-glass header, large elegant Roman-inscription serif headlines in ice white, clean sans-serif body text, hot-pink (#FF4D8D) buttons. Palette only navy, aqua, ice white and small touches of hot pink. Cinematic soft volumetric light, calm and expensive mood, crisp readable text. Avoid: car brand logos, real number plates, gold or yellow, people, extra or misspelled text, watermarks.
