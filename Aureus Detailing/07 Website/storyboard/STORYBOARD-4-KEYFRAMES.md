# Aureus website: 4 keyframes, concept "Into the Paint"

Written 16 Nov 2026 (replaces the foam version; the old one is in git history).

**The idea:** the website is a dive into a car's paint. You start with a whole car, a lens drops onto the bonnet, and you sink into the paint at microscope scale. There, swirl marks are canyons that get polished flat in front of you, the metallic flake glitters like a galaxy, and ceramic coating grows over the surface like crystal. Each package is a deeper layer: **Silver = the surface, Gold = the clear coat, Aureus = the ceramic shield**. It shows customers what detailing actually does.

## Where to generate
In Higgsfield (Plus account), open **Projects → Aureus Detailing** and generate there, so all keyframes and clips stay together. Claude saves its own generations into the same project.

## How to keep the 4 images consistent
1. **Make keyframe 2 first** (the master hero). Pick the best result.
2. Attach **that image and the logo** (`Aureus Detailing/02 Logo/Icons/social-profile-1080.png`) as references for keyframes 1, 3 and 4.
3. Same settings every time: **Nano Banana Pro, 16:9, 2K** (about 2 credits per image; 4K for finals). It's photoreal, renders text well and holds up to 14 reference images, which keeps all four frames consistent. Backup if text comes out garbled: **GPT Image 2.6, quality high, 2K, 16:9** (about 2.75 credits). Use the same model for all four. Reuse the master's seed if shown.
   Video later: **Seedance 2.5**, mode omni_reference, each clip given a start image and an end image (two keyframes).
4. Never change the look block. Only the scene changes.
5. Save as `kf1-lens.png`, `kf2-polish.png`, `kf3-layers.png`, `kf4-ceramic.png` in this folder.

## Video plan (after the 4 images exist)
- **Clip A, kf1 → kf2:** the camera falls through the lens into the paint. A polishing pad sweeps across, and the swirl canyons melt flat into a mirror.
- **Clip B, kf2 → kf3:** the camera sinks down through the paint and the layers open up like geological strata, each lighting up as its package.
- **Clip C, kf3 → kf4:** ceramic crystal grows across the top layer and a water drop beads and rolls off. The booking card locks in with a crystal tick.
