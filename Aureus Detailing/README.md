# Aureus Detailing: brand assets

Mobile and workshop car detailing by Monsoor Motors, 530 Albany Hwy, Victoria Park WA.

| Folder | What's inside |
|---|---|
| `01 Brand Guidelines/` | `Brand-Basics.md` (name, colours, fonts, packages, rules) and `Aureus-Logo-Usage-Guide.png` (one-page logo guide) |
| `02 Logo/` | The logo kit: `SVG/` vector masters, `PNG/` transparent images, `Icons/` (app icon, favicon, social profile). The README there says which file to use where |
| `03 Mockups/` | The logo on Instagram, business cards, the website and a uniform patch. `Website hero car/` holds the two full-size hero images (clean and foam-covered) |
| `04 Fonts/` | Montserrat (free commercial licence included), the brand font |
| `05 Share/` | `Aureus-Logo-Kit.zip`: everything a printer or designer needs, in one file |
| `06 References/Website/` | Inspiration for the Aureus website (e.g. the Octaboot 3D scroll car wash site), with notes on what to borrow |
| `07 Website/` | The Aureus Detailing website (version 2): `index.html`, `privacy.html`, `terms.html`, `404.html` and `assets/`. `BUILD-PROMPT-V2.md` is the brief the current version was built from (`BUILD-PROMPT.md` is version 1, kept in `_v1/`); `PRODUCT.md` lists open questions for the owner |
| `08 Social Media/` | Instagram and TikTok setup: `Instagram-TikTok-Setup.md` (handle @aureusdetailing.com.au, bios, steps, launch plan, rules), `Profile/` picture and `Highlight Covers/` (made by `Tools/aureus_highlight_covers.py`) |
| `99 Archive/` | Earlier logo rounds and unused fonts, kept for reference; don't use these |

The files are generated by `Tools/aureus_kit.py` (logo files and icons) and `Tools/aureus_presentation.py` (mockups and usage guide).
