# Aureus Detailing logo kit

Approved logo: the 3D Mirror A (Round 7). An open A standing on a mirror finish, with a hot-pink cap, one aqua highlight and an aqua reflection.
The one-page guide is `01 Brand Guidelines/Aureus-Logo-Usage-Guide.png`, and real-world examples are in `03 Mockups/Aureus-Mockups.png`.

## Which file to use

| Need | Use |
|---|---|
| Van, signage, Instagram posts, website, anything on navy | `aureus-horizontal-3d-chrome` or `aureus-stacked-3d-chrome` |
| Hero logo on white or light backgrounds | `aureus-horizontal-3d-navy` / `aureus-stacked-3d-navy` |
| Invoices, quotes, forms, small print on white | `aureus-horizontal-flat-color` |
| Embroidery, vinyl cutting, small print on navy | `aureus-*-flat-reverse` |
| One-colour printing, stamps, engraving | `aureus-*-flat-black` / `aureus-*-flat-white` |
| Symbol alone (profile pictures, stickers, app) | `aureus-symbol-*` |
| Very small (24 px and below) | `aureus-symbol-small-color` / `aureus-symbol-small-reverse` |

- `SVG/` holds vector masters (scale to any size, for printers and designers).
- `PNG/` holds transparent PNGs: symbols at 1024 px, lockups at 2x.
- `Icons/`:
  - `app-icon-1024.png`, `icon-512.png`, `icon-192.png`, `apple-touch-icon-180.png`
  - `social-profile-1080.png` (safe for a circle crop)
  - `favicon.ico`, `favicon-32.png`, `favicon-16.png`

## Colours
| Colour | HEX | RGB | Use |
|---|---|---|---|
| Deep navy | #071A33 | 7 26 51 | about 60%: backgrounds, van, uniforms |
| Deep aqua | #00A8A8 | 0 168 168 | about 30%: reflection, highlights |
| Hot pink | #FF4D8D | 255 77 141 | about 10%: logo cap, Book now, prices |
| Ice white | #F5F8FC | 245 248 252 | text and logo on navy |

The CMYK values on the guide are approximate. Ask the printer for a proof, or a Pantone match, before large print runs.

## Rules
- **Clear space:** keep a margin at least the height of the AUREUS letters on every side.
- **Minimum sizes:**
  - 3D symbol: 32 px / 12 mm
  - flat symbol: 24 px / 8 mm
  - smaller than that: use the small-size symbol
  - horizontal logo: at least 140 px / 35 mm wide
- **Don't** stretch the logo, recolour the A, add shadows or glows, place it on busy photos, or use the 3D version below 32 px.

## Production notes
- **Fonts:** the wordmark is Montserrat Medium (SIL Open Font License, free for commercial use), converted to vector shapes, so no font needs installing.
- **Files that are print-ready as-is:** the flat files are plain shapes, ready for embroidery, vinyl and laser cutting.
- **Files to flatten first:** the 3D files use gradients and a fading mask, which is fine for screens and full-colour print. For sign makers who need flat artwork, send the flat files, or ask a designer to flatten the 3D one.
- **Trademark:** no clearance search has been done. Run an IP Australia search before printing signage or vehicle wraps.
- **Generator:** the files are generated by `Tools/aureus_kit.py` and `Tools/aureus_presentation.py`, with the 3D logo itself in `Tools/aureus_logo_3d.py`.
